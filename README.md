## Featured Projects

### GridEnv AI — RL Bidding for Grid-Scale Batteries
Reinforcement-learning platform that optimizes battery energy storage (BESS) bidding into ERCOT wholesale electricity markets — a decision-and-action layer that turns price forecasts into live market bids.
- **RL core** trained against historical ERCOT price data and dispatch signals
- Built around regulatory context (FERC Orders 841 / 2222, RTC+B)
- Targeting the gap between forecasting tools and automated execution

### FilmTrends — Serverless Video Intelligence
Co-founder / CTO. Event-driven pipeline on AWS Lambda processing video at scale.
- Cut processing latency **90%** (5 min → 30 s) with an event-driven rebuild
- **78%** accuracy on viral-content prediction across 50+ engineered features
- **95+** Lighthouse score with a **40%** smaller bundle

### Layman — AI Article Summarizer · [GitHub](https://github.com/rohanreddy79/layman)
Cross-platform MVP built solo in **48 hours**. Any article → a 3-bullet summary.
- **RAG pipeline** — pgvector + Prisma + GPT-4 for retrieval and generation
- Custom model hosting on AWS Bedrock / SageMaker
- "Explain like I'm 5" layer over dense domain jargon
