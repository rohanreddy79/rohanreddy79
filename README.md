## 🏗️ Featured Project

### Layman — AI Article Summarizer · [GitHub](https://github.com/rohanreddy79/layman)

Cross-platform MVP built solo in **48 hours**. Processes any article into a crisp 3-bullet summary in **under 30 ms**.

- **RAG pipeline** — pgvector + Prisma ORM + GPT-4 for semantic retrieval and generation
- **Custom model hosting** — AWS Bedrock and SageMaker for fine-tuning and scalable inference
- **"Explain like I'm 5"** translation layer over complex domain jargon
- **Low-latency, scalable architecture** built event-driven from day one
